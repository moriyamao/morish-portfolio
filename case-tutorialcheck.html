TutorialCheck

An old tutorial can be correct for its original environment and fail in yours. TutorialCheck reviews pandas code for known migration issues and adds a trained risk score you can inspect.

Open the interactive demo → · Source, setup and model card ↗

Measured prototype · pandas 2.2.3

The implementation

The project includes a Python CLI, static browser demo, TF-IDF/logistic regression model, AST diagnostics, migration references and a reproducible training pipeline. Python and browser inference share the exported JSON model. Pasted snippets are reviewed without executing them.

The training fixtures cover eleven API migration families and valid Python list controls. Running those fixtures supplies the labels, and repaired cases include assertions about their results. This connects the model to observed execution outcomes rather than guessed compatibility labels.

The learned model has higher challenge recall (0.83 vs 0.67) but lower precision (0.67 vs 1.00). It catches additional patterns and also raises more false alarms. Its challenge F1 does not exceed the static baseline.

The generated holdout shares API families with training. Its perfect score is not evidence of real-world accuracy. The independent challenge is also small and project-authored; no external tutorial benchmark has been measured.

There are 414 generated snippets split 276/69/69 by recipe group, plus the 24 separate challenge cases. All 198 repaired fixtures ran and passed assertions. The mean F1 when excluding each entire API family from training is 0.88 across eleven small family tests. Model scores are uncalibrated, and the only execution-validated target is pandas 2.2.3.

Known errors include obsolete names in comments and strings, custom objects with valid append methods, and unfamiliar aliases. AST checks handle simple patterns rather than complete Python type inference. The release keeps these errors visible.

Reproduce it

Clone the repository, open projects/tutorialcheck, install its pinned requirements and run python -m tutorialcheck.train. Run python -m unittest discover -s tests -v for the verification suite, including numerical parity between browser and Python inference. The README contains complete setup instructions and the model card.

Migration references: official pandas removal notes and concat documentation. No pandas 1.x runtime comparison was performed, and passing fixture assertions does not prove arbitrary replacements preserve semantics.
