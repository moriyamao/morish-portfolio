Multilayer Perceptron, built from scratch

A two-layer neural network implemented in NumPy only — no scikit-learn, no PyTorch, no TensorFlow doing the actual learning. The point wasn't to get a good accuracy number; it was to prove I understood what a framework normally hides.

no framework, forward + backward pass written by hand

The problem

It's easy to call model.fit() and never actually understand backpropagation. This project removed that option: build a working MLP where every matrix multiplication, activation, and gradient update is code I wrote and can explain line by line.

What I did

  • Implemented a two-layer MLP from scratch in NumPy — weights, biases, and the training loop, with no high-level ML framework handling the learning itself.
  • Wrote forward propagation and backpropagation by hand, with configurable activation functions.
  • Trained with mini-batch gradient descent, and evaluated using separate training and validation metrics rather than trusting a single training-accuracy number.
  • Experimented with different hyperparameters and network configurations to see how each one actually changed training behavior, not just the final score.

What came of it

A working, reproducible Jupyter Notebook that trains end to end and that I can walk someone through without hand-waving over the math — the honest test for a from-scratch project like this isn't the accuracy number, it's whether I can explain every line when someone asks "wait, why that gradient?"
