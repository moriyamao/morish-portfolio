What this audit can and cannot establish

Exact row matches, shared entities and timestamp interleaving are observations. Their relevance depends on the intended deployment. The tool cannot infer feature collection timing, recover preprocessing history, or prove that a model’s score is inflated from CSV files alone. The Python CLI also searches a bounded numeric sample for near matches; this browser view does not.
