    This is a focused research prototype with 414 generated fixtures and 24 separately authored challenge snippets. Generated recipe holdout is easier than unfamiliar real tutorials; it is not a real-world accuracy estimate. The model is not calibrated, the rules cover a limited set of removed APIs, and replacement examples do not prove equivalence for your code. Unknown inputs can make the model abstain. Other pandas versions are outside the evaluated scope.

    Migration history is grounded in official pandas release notes. No runtime comparison against pandas 1.x was performed.
